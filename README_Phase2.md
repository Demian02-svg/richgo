# Rich Go - Phase 2 시스템 알림

## Phase 1 (인앱)
- 홈 상단 🔔 알림 카드 (연체/오늘/D-3/부분납부)
- 인앱 알림 센터 리스트

## Phase 2 (시스템 알림) - NEW
- 브라우저 Notification API 사용
- 설정 탭에서:
  - 시스템 알림 켜기/끄기
  - 알림 시간 설정 (기본 09:00)
  - 건물 필터 (전체 or 특정 건물만)
  - 종류 토글: 연체 / 오늘 / D-1 / D-3(2~3일전) / 부분납부
  - 권한 요청 버튼 / 테스트 알림 버튼
  - 마지막 발송일 표시
- 매일 9시 이후 첫 앱 진입 시 자동 발송
  - 이미 오늘 발송했으면 중복 발송 안 함
  - 1분마다 시간 체크 (앱이 열려 있을 때)
  - visibilitychange 시에도 체크
- sw.js v3:
  - notificationclick 시 앱 포커스/열기
  - 캐시 버전 v3로 갱신
  - periodicsync 대비 (실험적)

## 동작 방식 (서버 없음)
- 모든 데이터는 IndexedDB에만 저장
- 알림은 기기 로컬에서만 계산 (showNotification)
- iOS: PWA로 홈 화면에 추가 + 앱이 포그라운드일 때만 동작
- Android/데스크탑: 백그라운드에서도 알림 표시 가능 (권한 허용 시)

## 테스트
1. 설정 탭 -> 알림 권한 요청 -> 허용
2. 알림 종류 체크 (연체, 오늘 등)
3. 지금 테스트 알림 버튼
4. 매일 09:00 이후 앱 열면 자동 알림 오는지 확인
